# TRIP Travel — Perú sin límites

Sitio estático responsive (HTML, CSS y JavaScript), preparado para publicar en GitHub Pages. No requiere compilación ni dependencias.

## Publicar en GitHub Pages
1. Descomprime este archivo ZIP.
2. Sube **el contenido** de esta carpeta a la raíz del repositorio (donde debe quedar `index.html`).
3. En GitHub, abre **Settings → Pages** y selecciona la rama principal y la carpeta `/ (root)`.
4. Cuando termine la publicación, revisa la página de inicio, los tours, el menú móvil y el formulario de contacto.

## Archivos principales
- `index.html`: inicio y galería de destinos nacionales.
- `tours.html`: paquetes con filtros por Costa, Andes y Amazonía.
- `transporte.html`, `corporativo.html`, `nosotros.html`, `contacto.html`.
- `styles.css`, `script.js`, `assets/favicon.svg`.

## Fotografías
La galería muestra imágenes ilustrativas desde sus proveedores y necesita conexión a Internet. Si deseas alojarlas dentro de GitHub, descarga las fotos de sus páginas originales, conserva la atribución cuando corresponda y coloca los archivos en `assets/images/`; después reemplaza las URLs del HTML y CSS. Comprueba la licencia y que la foto represente correctamente el destino anunciado.
