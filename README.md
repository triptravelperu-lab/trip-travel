## Cómo publicar en GitHub Pages
1. Descomprime el ZIP.
2. Sube todos los archivos y la carpeta `assets/` al directorio raíz del repositorio.
3. En GitHub, entra a Settings → Pages.
4. Selecciona la rama principal y la carpeta raíz `/`. Guarda los cambios.
5. Espera a que GitHub muestre el enlace publicado y pruébalo desde un móvil.

## Medios
Las imágenes y el video se sirven desde proveedores externos (Unsplash y Pexels). Por eso, la web necesita conexión a Internet para mostrar estos medios y su disponibilidad puede cambiar. Antes de usar el sitio en producción, se recomienda revisar la licencia concreta de cada imagen y, para mayor estabilidad, guardar en `assets/images/` fotografías propias o aquellas con autorización de uso y actualizar las rutas. Algunas miniaturas de referencia pueden cambiar con el proveedor. El video está configurado para reproducirse sin sonido y el usuario también puede usar los controles del reproductor inferior.

## Importante
Los textos de precios y paquetes son referenciales y deben confirmarse antes de publicarlos como oferta vigente. Revisa también dirección, redes sociales y datos comerciales antes de lanzar la página al público.
