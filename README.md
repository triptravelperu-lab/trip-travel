# TRIP Travel · Servicios integrales de viajes y turismo

Sitio estático preparado para GitHub Pages. Presenta de forma organizada las líneas de servicio de TRIP Travel con atención desde Lima y alcance local, nacional e internacional.

## Estructura

- `index.html`: presentación general y solicitud inicial.
- `destinos.html`: inspiración de destinos nacionales e internacionales.
- `tours.html`: viajes, paquetes y excursiones receptivos, emisivos e internos.
- `vuelos.html`: gestión de pasajes aéreos, terrestres, marítimos y ferroviarios.
- `transporte.html`: transporte turístico, traslados, transfers, logística y alquiler de vehículos.
- `hoteles.html`: hospedaje, servicios gastronómicos y catering.
- `experiencias.html`: guiado, asistencia al viajero y orientación sobre seguros y trámites consulares/visados.
- `corporativo.html`: eventos, delegaciones, asesoría empresarial, marketing turístico, capacitación y consultoría.
- `tienda.html`: artículos de viaje, equipamiento, artesanías, souvenirs y tecnología.
- `conexiones.html`: herramientas externas para explorar vuelos, alojamientos, rutas y experiencias.
- `nosotros.html` y `contacto.html`: presentación y contacto.
- `trip-global.css`, `trip-global.js`: estilos e interacciones.
- `assets/images/`: imágenes y logos locales.

## Publicar en GitHub Pages

1. Descomprime el ZIP.
2. Sube todo el contenido de esta carpeta a la raíz del repositorio (incluida la carpeta `assets`).
3. Confirma los cambios y espera que GitHub Pages complete el despliegue.
4. Verifica `index.html` y visita también las páginas secundarias.

## Alcance y transparencia

- Las solicitudes del sitio son consultas o cotizaciones, no confirmaciones automáticas de reserva.
- Las páginas de conexiones externas llevan al usuario a servicios independientes. No se afirma que sean socios comerciales ni que su disponibilidad o tarifas estén garantizadas.
- La disponibilidad, condiciones, precios, emisión, seguros y trámites se validan con las entidades, proveedores u operadores correspondientes.
- La galería contiene imágenes de inspiración visual para el diseño; deben sustituirse por material propio o con licencia apropiada antes de campañas publicitarias específicas si se requiere fotografía documental auténtica de un destino.
