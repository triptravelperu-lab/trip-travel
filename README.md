# TRIP Travel — Servicios integrales y conexiones globales

Sitio estático listo para GitHub Pages. El diseño conserva la marca TRIP Travel y el WhatsApp de contacto **+51 954 021 718**. La empresa se presenta con base en Lima y cobertura de servicios local, nacional e internacional.

## Contenido

- `index.html`: página principal con cabecera compacta, hero con video local silencioso, buscador conectado a proveedores externos, destinos, categorías de servicio y CTA.
- Páginas de destinos, paquetes, pasajes, transporte, hospedaje, experiencias, corporativo, tienda, conexiones, nosotros y contacto.
- `trip-global-integrated.css`: estilos compartidos, responsive y del diseño visual principal.
- `trip-interactive-v7.js`: menú móvil, formularios que abren WhatsApp, tabs del buscador, consultas externas y control de movimiento del video.
- `assets/images/`: logo y fotografías locales.
- `assets/video/trip-world-loop.mp4`: montaje animado silencioso realizado a partir de las imágenes visuales incluidas en el proyecto; no es una grabación documental real.

## Publicación en GitHub Pages

1. Descomprime el ZIP.
2. Sube todo el contenido de esta carpeta a la raíz del repositorio `trip-travel` (no subas la carpeta como subdirectorio adicional).
3. Confirma los cambios y espera que GitHub Pages publique.
4. Recarga el sitio con `Ctrl + F5`.

## Cómo funciona el buscador

Los tabs preparan búsquedas en Google Flights, Booking.com, Google Maps, GetYourGuide u otros resultados externos. El sitio no simula precios o disponibilidad en tiempo real ni confirma reservas automáticamente. Para procesar inventario y reservas internamente se requieren API y acuerdos/autorizaciones con los proveedores correspondientes.
